# AppMethodsHub

Protótipo estático do Applied Methods Hub, preparado para publicação pelo GitHub Pages. Os livros permanecem nos repositórios e páginas em que já estão publicados; esta página funciona como catálogo central.

## Prévia do movimento

Para ver a animação completa, abra `movimento-dados.html` no Chrome ou Edge. Essa demonstração independente reúne HTML, CSS e JavaScript no mesmo arquivo. O movimento percorre seis momentos: observar a realidade, formular a pergunta, reunir evidências, escolher o método, construir o modelo e interpretar os resultados.

Para ver a página completa, abra `index.html` com os arquivos `styles.css`, `app.js` e a pasta `assets` no mesmo diretório. A biblioteca inclui uma distribuição normal e uma curva de sobrevivência em movimento, ambas identificadas como esquemas sem dados empíricos. Os elementos das seções aparecem ao rolar; as ilustrações dos cartões também têm movimentos próprios.

O clique na assinatura de Alexandre Nicolella abre o vídeo de apresentação. O site seleciona a versão horizontal em telas grandes e a vertical em celulares. Os dois arquivos de vídeo estão em `assets/`.

Não há dependências de build. As fontes Outfit, Inter e JetBrains Mono são carregadas do Google Fonts.

## Publicação

Copie o conteúdo desta pasta para o repositório `AppMethodsHub` e configure o GitHub Pages para publicar a raiz da branch principal. O endereço esperado é `https://anicolella.github.io/AppMethodsHub/`.
